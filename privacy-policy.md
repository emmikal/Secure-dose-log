# Secure Dose Log Privacy Policy

**Effective date:** August 31, 2026

Secure Dose Log is a privacy-focused Android application for recording and reviewing personal substance-use and dose information.

This Privacy Policy explains what information Secure Dose Log stores, how it is handled, and what information is shared with third parties.

## 1. Developer

**Emmi Kallioniemi**

## 2. Information stored by the app

Secure Dose Log allows users to record information including:

- Substance or drug name
- Route of administration
- Dosage
- Date and time of an entry
- User-provided notes
- Linked substance information
- Session information
- Statistics derived from the user's entries

Some of this information may be sensitive personal or health-related information.

## 3. Where your data is stored

Secure Dose Log is designed as a local-first application.

Your dose-log data is stored locally on your Android device in an encrypted SQLCipher database.

Secure Dose Log does not require an account and does not operate a cloud service for storing your dose-log information.

The developer does not receive your dose-log data.

## 4. Data collection and sharing

Secure Dose Log does not collect or transmit your dose-log information to the developer or to third-party servers.

The application does not contain:

- Advertising
- Third-party advertising trackers
- User analytics
- Social networking functionality
- Developer-operated cloud synchronization

Secure Dose Log does not sell your personal information or dose-log data.

## 5. CSV import and export

Secure Dose Log allows users to export their dose log as a CSV file.

Exported files are stored using Android's file-storage mechanisms. Once a file has been exported, the user is responsible for how that file is stored, transferred, or shared.

Secure Dose Log also allows users to import CSV files selected through Android's document picker.

Imported information becomes part of the user's local dose log.

Users should only import files from sources they trust.

## 6. Android backups

Secure Dose Log does **not** include its dose database or encrypted preferences in Android cloud backups or device-to-device transfers.

This means your dose history will not automatically be restored when moving Secure Dose Log to another device.

Users who want to transfer their dose history to another device can use the application's CSV export and import functionality.

## 7. Security

Secure Dose Log uses encryption to protect locally stored dose-log information.

The local database is encrypted using SQLCipher.

Sensitive database credentials are protected using Android Keystore-backed encryption.

The application can also use Android device authentication to restrict access to the dose log.

No security measure can guarantee absolute protection. Users should protect their Android device with an appropriate screen lock and keep their device software up to date.

## 8. Third-party content

Secure Dose Log includes a bundled substance-reference database containing information derived from PsychonautWiki.

This reference data is included in the application package and is not fetched from PsychonautWiki while the application is being used.

Secure Dose Log is not affiliated with or endorsed by PsychonautWiki.

PsychonautWiki content is used in accordance with its applicable licensing terms. Attribution information is included with the application.

## 9. Permissions

Secure Dose Log does not require access to:

- Contacts
- Location
- Microphone
- Camera
- SMS
- Phone calls

The application does not intentionally collect persistent device identifiers for the purpose of tracking users.

## 10. Data retention and deletion

Secure Dose Log does not retain dose-log information on developer-operated servers.

Your dose-log data remains on your device until you delete individual entries, delete the application's data, or uninstall the application.

Exported CSV files are separate files managed by the user and must be deleted separately if the user no longer wants to retain them.

Because Secure Dose Log does not provide user accounts or a developer-operated cloud database, there is no server-side user account or dose-log dataset for the developer to delete.

## 11. Children's privacy

Secure Dose Log is not intended for children.

The application is intended for adults and does not knowingly collect personal information from children.
